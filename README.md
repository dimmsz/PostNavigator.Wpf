# Post Navigator

Xのプロフィールを開き、アカウントと年月を指定して過去の投稿を探せるWindows向けアプリです。アプリの操作画面はWPFのFluentテーマでWindowsのライト・ダーク設定に連動し、XのページはMicrosoft Edge WebView2で表示します。

## 起動

1. Visual Studio 2026で「.NET デスクトップ開発」ワークロードと.NET 10 SDKを用意します。
2. Microsoft Edge WebView2 Evergreen Runtimeが入っていない場合は[Microsoftの配布ページ](https://developer.microsoft.com/microsoft-edge/webview2/)から導入します。
3. `PostNavigator.Wpf.slnx` を開き、F5で起動します。

コマンドラインでは `dotnet run --project PostNavigator.Wpf/PostNavigator.Wpf.csproj` で起動できます。

## 使い方

1. アプリ右上の「Xにログイン」からログインします。ログイン情報はWebView2がアプリ専用のプロファイルに保存します。
2. ユーザー名（例 `@cissan_9984`）またはプロフィールURLを入力します。起動時はcis氏のプロフィールが開きます。
3. 「プロフィール」「返信タブ」でタイムラインを開けます。古い投稿を探すには、年と月を選んで「この期間の投稿を検索」を押します。「通年」を選ぶと年全体を検索します。
4. 検索結果はXの「最新」タブに表示されます。件数と日付の判定にはXの検索仕様が適用されます。

## 表示中の投稿を保存

「設定」で保存先の接続文字列を登録し、接続先のデータベースに `x_posts` テーブルを作成してください。投稿一覧で「表示中の投稿を取得」を押すと、画面に一部でも見えている投稿をデータベースに保存し、件数を画面下に表示します。次の投稿を保存するには、Xの画面をスクロールしてもう一度押します。

保存する項目は投稿ID、投稿者のユーザー名と表示名、画面から読み取った本文、投稿日時（UTC）、投稿URL、本文の省略フラグです。「さらに表示」で折りたたまれた投稿では、画面に読み込まれている本文を保存し、省略フラグを設定します。

投稿の添付画像は `%LOCALAPPDATA%\PostNavigator\PostArchive\media\<投稿ID>\` に保存します。投稿IDごとの `posts\<投稿ID>.json` に、添付種別と番号、元のXのリンク、配信元URL、保存ファイルの相対パスを記録します。動画は画面から直接取得できるMP4とサムネイルが対象です。ファイルを取得できなかった添付は元のXのリンクを記録します。以前に保存した投稿の添付も、その投稿を再び表示して取得すれば追加できます。

アカウントと年月を選んで「この期間の投稿をHTMLに書き出す」を押すと、保存先に `index.html`、添付ファイル、対応表 `attachments.json` を含むフォルダーが作られます。HTMLは保存した画像を相対パスで参照するので、フォルダー全体を移動しても閲覧できます。

「自動取得」をオンにすると、画面内に表示された投稿を定期的に確認してデータベースに保存します。オンにしている間に一度保存した投稿は、本文や表示情報に変化があったときに再保存します。オフにすると自動取得が止まり、アプリを起動し直すとオフから始まります。

投稿一覧で「自動スクロール」の「上へ」「下へ」を押すと、選んだ方向にゆっくり進みます。途中で方向を切り替えたり、「停止」で止めたりできます。下端では待機し、追加の投稿が表示されると自動で再開します。上へ進むときは、上端で約3秒間動かなければ停止します。自動取得をオンにしておくと、スクロール中に表示された投稿も保存します。

上下に何度かスクロールすると、戻ってきた投稿も再確認し、未保存の投稿や長い本文を補完します。スクロールとDOMの変化でも読み取り、DB保存中に検出した投稿は保存待ちとして保持します。一時的なDB接続エラーは再試行します。「さらに表示」を開くと展開した本文を再保存します。スイッチの下に表示する「検出」「保存確認」の件数は、そのスイッチをオンにしてから読み取れた投稿IDの件数です。「保存待ち」は追加・更新の保存が完了していない件数です。

## MySQL・MariaDB用のSQL

右上の「設定」でMySQLまたはMariaDBの接続文字列を保存できます。通常は入力内容が伏せられ、「接続文字列を表示」で確認できます。保存内容はWindowsのユーザー単位で暗号化されます。空欄を保存すると削除されます。

「接続テスト」を押すと入力中の接続文字列で実際にデータベースへ接続し、結果を表示します。保存前の入力でも試せます。投稿の保存には、`x_posts` に対する SELECT・INSERT・UPDATE 権限が必要です。

[テーブル作成](sql/001_create_x_posts.sql)を、保存先のデータベースを選んで実行します。投稿IDは `XPost.Id` と同じ文字列で保持し、主キーにします。日時は投稿日時とデータベースの初回・最終保存日時をUTCで保持します。

[保存クエリ](sql/upsert_x_post.sql)は、同じIDの投稿があれば更新します。保存済みの完全な本文を省略版や空欄で上書きせず、省略版同士では長い本文を優先します。ボタン1回分の保存は1つのトランザクションで処理します。

[一覧クエリ](sql/select_x_posts_by_author.sql)は、`@AuthorHandle` に先頭の `@` を除いたユーザー名、`@StartUtc` と `@EndUtc` に検索期間の開始と終了を渡します。開始日時を含み、終了日時を除きます。
